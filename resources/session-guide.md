# 完整学习与关系复盘流程

一个入口覆盖整期内容，不代表每次都要把所有问题问一遍。只有用户明确要求完整学习或全面复盘时，才按以下七个子任务展开；每个子任务载入对应能力卡并执行，单次一至两卡。

## 先确认范围

确认是学习视频，还是分析真实关系。学习模式可以讲原理与合成示例；真实关系模式只使用本人提供的信息，对方答案全部待核实。用户不愿提供隐私时给空模板即可。

先说明：作者提出经验性体会，不提供一套测出是否相爱、一定能走下去的算法。遇到威胁、强迫或无法安全表达，停止普通双方沟通流程，不把全面覆盖作为逼迫完成练习的理由。

## 七个子任务

1. **自我与经历**：载入 self-grounding；辨认关系之外真实存在的生活与能力，不强迫积极化失去。
2. **个人空间**：载入 personal-space；把独处事实、解释与情绪分开，未协商的恢复沟通方式保留待商量。
3. **期待表达**：载入 explicit-expectations；区分自愿付出、未说的期待与已经达成的约定。
4. **共同生活**：载入 deep-conversation；检查钱、孩子、工作居住、空间边界、家务、争吵处理和收入变化，记录一致、差异及未知。
5. **持续经营**：载入 sustainable-attraction；计入身体与照护负担，选择本人也愿意的可承受行动。
6. **外界意见**：载入 outside-opinions；整理观察、解释、建议与信息缺口，保留求助和本人选择。
7. **五问核对**：载入 partner-five-questions；先预想，再自愿向本人核实，不评分。

## 完成与未完成

对每项记录“本次不适用／待本人信息／个人整理完成／待伴侣核实／双方已有确认”。这些状态是整理者约定，不是原片量表。

没有伴侣参与时，最多完成个人整理；不能为了填满七项编造对方立场。用户只想先做一项时，记录其余待完成并尊重选择，不把练习变成义务。

## 最终交付

用一页汇总：已知事实、当前差异、未知信息、真实约定、尚未确认的提议、本人愿意的下一步。不要给总分，不替用户决定继续或离开；不能把完成表格称为修复关系。
