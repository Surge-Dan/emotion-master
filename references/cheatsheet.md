# 决策规则速查 — 关于爱情，我终于想明白了几件事

| 能力 | 一句话规则 |
|---|---|
| 关系之外的自我与经历回顾 | 承认失去的重要性，再从具体往事中辨认仍然存在的生活与能力，不用下一任更好来跳过当下。 |
| 独处需求与情绪整理 | 把独处的事实、自己对它的解释和待表达的情绪分开，允许整理后再沟通，不凭一个举动判定爱意。 |
| 把隐形期待变成具体表达 | 期待可以有，但不要用未告知的账本索取回报；把实际需要说清，也听清对方的需要。 |
| 共同生活议题与动态复盘 | 在平静时谈清想过的生活与具体选择，并更新已改变的需求；相爱不能代替这些答案。 |
| 稳定关系中的自我经营 | 在自己的身体、时间和资源范围内保持认真生活与彼此用心，不将吸引力变成体型或年龄考核。 |
| 听取外界意见与自主选择 | 把外界的观察、解释与建议拆开，再核实事实、自己的感受和接受范围，保留求助与自主决定。 |
| 五问更新对伴侣的认识 | 先记录自己对伴侣当下状态的预想，再向本人核实，以差异更新认识而不给关系打分。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
