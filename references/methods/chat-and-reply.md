# 聊天证据与回复编排

用于聊天记录分析、暧昧互动、接话、邀约和回复草稿。方法结合上游项目的证据拆分、单轮目标、三层表达、口吻校准及反馈分支，来源见仓库根目录 NOTICE.md。

## 先看得到的内容

确认用户与对象的说话人映射、当前关系、最近上下文和用户想完成什么。只有一条消息时，用当前信息给暂定回复。需要追问时，优先问真正会改变措辞或方向的一项。

| 项目 | 记录方式 |
|---|---|
| 已知事实 | 可见原话、发起与回应、实际安排、兑现与取消 |
| 本人感受 | 用户自己表达的期待、委屈、喜欢、担忧 |
| 暂定解释 | 可能的理解及其依据，保留其他解释 |
| 关键未知 | 关系阶段、具体情境、对方是否同意或给出替代安排 |

输出判断时，明确哪项行为支持该判断。对方未表态的事情保留为待确认。

## 给本轮选一个主目标

| 互动情况 | 主目标 | 本轮交付 |
|---|---|---|
| 对方倾诉、分享、受挫或开心 | 承接 | 回应具体内容与感受 |
| 对方忙、累，用户刚连续追问 | 降压 | 留出轻松、可以晚些回应的空间 |
| 双方自然接梗，愿意来回延展 | 调侃 | 接住梗，留一个容易接的话头 |
| 对话顺畅，用户希望多了解一步 | 轻推 | 真诚表达兴趣或提出小的下一步 |
| 共同兴趣和时间线索较清楚 | 约见 | 一个有具体安排、可以拒绝的邀请 |
| 一个未知会改变当前判断 | 澄清 | 一个明确、容易回答的问题 |
| 持续失衡、明确拒绝或边界不合 | 收线 | 表达边界，结束当前推进方向 |

一句话以一个主目标为中心。必要时增加一个轻辅助动作。

## 选择表达的材料

- 逻辑材料包括事实、时间、地点、选项、问题和边界。
- 情绪材料包括幽默、画面、轻微调侃和语气。
- 情感材料包括理解、欣赏、真实感受和关系意愿。

承接与修复优先照顾理解和感受。邀约把安排说清楚。调侃以对方当前接得住的程度为准。按任务选择所需材料。

## 校准口吻

沿用用户平时的长度、词汇、标点和亲密程度。初识与长期伴侣使用不同称呼。文字优先简洁，通话和线下表达留出停顿与对方回应的空间。称呼、性别与关系约定依据实际资料。

需要临时举例时，明确写“假设场景”，然后替换成用户确实提供的细节。

## 先给能发的那句，再给分支

默认输出一条首选成品、一句适用理由和必要的后续分支。用户要求比较口吻时，再给两三个可选版本。

| 对方实际反馈 | 接下来怎么调 |
|---|---|
| 主动延展、反问、给时间或接住邀请 | 沿对方回应具体化下一步 |
| 礼貌但含糊，暂时没有新信息 | 结束本轮追加，等待新的时间或情境信息再判断 |
| 拒绝某个时间但主动提出替代安排 | 围绕替代安排继续确认 |
| 明确拒绝发展、要求停止或出现不适 | 停止该方向，简短确认对方边界 |

回复草稿代表用户自己的意图。模拟回复属于演练，需要根据现实反馈重新判断。

## 对话演练

先选破冰、接话、邀约、澄清或修复等场景，再让用户选择实时提示或事后复盘。每轮给一条模拟回复，等用户接话。复盘一个具体做得好的地方和一个可以调整的地方，再给替代表达。

完成标准是用户得到符合当前目标、口吻和事实的一条表达，以及面对关键反馈时可以调整的下一步。
