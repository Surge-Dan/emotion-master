# 投入校准与行动分支

用于冷淡、节奏不同、反复取消、单向付出，以及是否继续主动的问题。依据实际事件选择下一步，方法来源见仓库根目录 NOTICE.md。

## 先定位当前状态

| 状态 | 可以观察的证据 | 可考虑的动作 |
|---|---|---|
| 互惠但节奏不同 | 回复慢却说明情况、提供替代时间、兑现约定，投入形式可以协商 | 表达偏好，商量双方都能接受的节奏 |
| 证据不足 | 刚认识、互动太少，或存在考试、照护、疾病等情境 | 选择一次能获得新信息的具体提议或澄清 |
| 持续失衡 | 长期单方主动，反复失约，表达需要后持续回避且缺乏修复 | 调整投入，说明边界，选择可观察的停止条件 |
| 明确拒绝或存在危险 | 明确要求别联系，或出现威胁、强迫、跟踪和暴力 | 停止推进，按情况支持退出与安全求助 |

状态是当前材料支持的暂定判断。用户提供新事实时，更新判断。

## 回看有代表性的事件

优先问清最近几次互动中的具体行为。

- 谁发起见面、联系或下一步，对方不能参加时是否给替代方案。
- 已有约定是否兑现，取消时是否说明并补救。
- 本人表达需要后，得到怎样的实际回应。
- 冲突后是否有人承担影响，并落实改变。
- 双方是否能保留朋友、个人生活和拒绝的空间。

每项分成已发生、本人解释和仍未知。回复间隔、礼物、点赞与偶尔热情要结合整体情境理解。

## 从状态落到动作

### 证据不足时，争取新的现实信息

用户希望推进且对方仍愿意互动时，可提出一个具体、容易回应的邀请或表达。存在关键误解时，先澄清。提出后观察实际回应。

### 将观察窗口绑到事件

用下一次约见是否兑现、考试后是否恢复联系、下一轮排班是否给出安排等自然事件判断进展。窗口的事件来自真实情境，需要与用户确认。

### 持续失衡时，调整投入

帮助用户选一项可以承受的调整，比如减少单方面策划、降低超出当前关系的额外投入，或把时间放回自己的生活。请用户想想，即使对方没有追上来，这项调整是否仍然符合自己的需要。

### 选择具体停止条件

由用户结合真实行为与接受范围选择条件，例如再次无解释失约，或再次跨越已经表达的边界。达到条件后，整理用户愿意采取的行动。共同工作、学习或抚养场景中，必要事务沟通可以单独安排。

## 输出

先给当前状态及其证据，再给一个首选动作。写清要观察的事件、会改变判断的新信息，以及需要用户自己确认的边界。真正存在权衡时，再比较其他选择。

把未表达的期待、已经表达却未达成一致、已有约定未履行分别记录。需要表达具体请求时，联用期待表达能力。涉及共同生活安排时，联用深度沟通能力。

完成标准是得到有事实依据的下一步和可观察的反馈。依据双方行为更新判断，最终选择由用户作出。
