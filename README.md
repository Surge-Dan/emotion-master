你的情感大师，教你暧昧追求、聊天分析与回复、长期相处、冲突修复和分手复盘，结合情绪支持、自我觉察、事实梳理及双方需求与投入分析，帮你看清关系、搞懂自己，关键时刻递上话术和行动建议，争取让你登上爱情的巅峰，别半路谈成了爱情的牛马！

优先服务长期关系与婚姻经营，面向成年人的不同性别、性取向与家庭结构。默认你一个人来聊，从眼前最卡的事开始，给出明确首选、依据和代价，最后由你决定。

## 能帮你解决什么

| 你遇到的事 | 情感大师会怎么帮 | 这一轮能拿到什么 |
| --- | --- | --- |
| **暧昧、邀约、这句怎么回** | 看清上下文和互动阶段，贴合你的口吻组织表达 | 一条可发送的回复，以及接受、含糊或拒绝后的下一步 |
| **聊天截图越看越上头** | 核对说话人、顺序与时间，分清事实、感受和推测 | 有出处的分析，以及真正需要核实的问题 |
| **总是自己主动、付出、等消息** | 结合主动、兑现、回应与修复，梳理投入和现实限制 | 继续推进、调整投入或退出的建议与代价 |
| **同一件事吵了八百遍** | 还原冲突怎样升级，找到可改变的一步 | 一句开场、一份修复草案和失约后的处理分支 |
| **家务、育儿、照护全靠自己盯** | 把发现、规划、执行和跟进都摊开商量 | 一份完整责任分工草案，标清待确认项 |
| **钱、父母、工作、生育谈不拢** | 梳理各自需要、底线、资源和可行选项 | 一次谈话的议程，以及需要双方同意的安排 |
| **信任破裂、亲密差异、关系变淡** | 区分已知问题与猜测，讨论边界、修复条件和日常连接 | 一次核实谈话、具体请求或共同活动提议 |
| **要不要继续，已经想分开** | 尚未决定时比较路径，已决定时接上执行准备 | 首选建议、依据、代价和准备清单 |
| **失恋后想重新找到自己** | 整理经历、需要和可用支持，照顾现实生活 | 一份复盘，以及今天能做的一步 |

## 第一次用，直接开聊

安装完整 Skill 目录后，对 Agent 说。

```text
使用 $emotion-master。
我们在一起三年，最近总因为小事吵架。
先帮我捋清最近这一次发生了什么，再看看我能怎么开口。
```

第一次默认了解三件事，已有的信息会沿用。

1. 你们目前是什么关系、处于哪个阶段。
2. 最近发生了哪件具体的事。
3. 这次最想解决什么，例如先被听见、回一句话、谈分工或作选择。

可以直接贴文字、发截图或提供文件，年龄段、同住、孩子、工作和资源按当前问题逐步补充。急着回消息时，会先给一个可用版本，再补影响措辞的关键背景。

### 💬 先救一下这条消息

```text
使用 $emotion-master，帮我看这张聊天截图。
右边是我，左边是他。先给一句我能直接发的话，口吻自然一点，
再告诉我判断依据，以及他答应、含糊和拒绝时分别怎么办。
```

### 🧺 把家里的分工谈明白

```text
每次说家务，他都说“你告诉我做什么不就好了”。
但发现问题、安排和提醒也很累。
帮我今晚先谈一项他能完整负责的事，给开场和分工草案。
```

### 🧭 认真判断这段关系

```text
我想判断这段关系该不该继续。
请根据我提供的事实给一个明确首选，讲清依据、代价，
以及什么新信息会让你改变建议。缺少决定性信息就直接问。
```

### 🔄 上次聊过，这次接着捋

```text
上次我准备谈周三的哄睡安排，但还没开口。
现在一想到他可能拒绝就不想谈了。
先帮我看看卡在哪里，把下一步缩小一点。
```

## 情感大师怎么工作

| 环节 | 会做什么 | 判断和交付 |
| --- | --- | --- |
| **明确本轮目标** | 先接住当前感受，确定这次最需要哪种帮助 | 情绪支持、回复、协商、修复、选择或复盘 |
| **核对实际材料** | 阅读文字、截图或文件，标出来源和缺失上下文 | 事实、本人感受、解释假设与未知分开 |
| **找到关键问题** | 梳理需要、互动循环、现实约束与过去尝试 | 区分没说清、没资源、不同意和持续拒绝 |
| **形成首选建议** | 按问题加载相关知识，比较可行路径 | 明确首选、依据、代价和改变判断的条件 |
| **落到具体行动** | 给话术、谈话议程、分工草案或个人行动 | 本人能做的事与需要双方同意的事分别标清 |
| **按真实反馈调整** | 看实际做了什么、对方怎样回应、哪里执行不了 | 更新建议与案例，需要时转协商、边界或选择 |

你可以直接要一句回复，也可以深入梳理整段关系。当前信息足够完成的部分会先交付，后续需要的信息留到相关步骤再补。

## 核心能力

### 💌 聊天分析与回复编排

根据关系阶段、上下文、本轮目标和你的口吻给出成品，再接上不同反馈的后续动作。投入判断关注持续主动、兑现、回应需要和冲突修复，保留单次延迟、表情和礼貌回应的解释空间。

### 🏠 长期相处与共同生活

围绕家务、育儿、照护、钱、父母、生育、居住与工作等具体问题，把委屈整理成可讨论的需要和安排。分工会考虑规划与跟进，也会考虑时间、身体、收入、照护和可用帮助。

### 🧩 冲突修复与关系选择

复盘一次真实冲突怎样升级，选择可以中断循环的一步，跟进补救和履行。反复明确表达仍被拒绝时，会重新评估意愿、边界与选择。用户已经决定分开，就围绕该目标提供执行准备。

### 📎 文字、图片与文件分析

聊天原文、截图和文件都可以作为材料，按实际读取范围判断，并尽量定位到具体消息、页码或段落。说话人不明、图片模糊、日期缺失或材料矛盾时保留未知，补充会影响建议的关键位置。

图片识别、文件解析和音视频转写取决于所用工具的实际能力。读取失败时会说明缺失范围，并请你提供相关片段或清晰截图。

### 📚 按任务查阅的知识库

14个领域覆盖情绪与自我、需要与回应、冲突与修复、家务与照护、金钱与规划、信任与背叛、关系选择、家庭与转折、亲密与同意、积极连接、暧昧与聊天、分离与恢复、现实约束，以及安全与专业支持。

每张卡都包含适用问题、操作步骤、具体交付、反馈分支和限制。原视频的七项能力继续保留时间戳与原文定位。[查看知识地图](references/knowledge/index.md)

## 本地档案与持续跟进

想下次接着聊，可以选择在指定的本机私人目录保存精简档案。首次说明保存内容、路径和隐私后，取得你的明确同意才启用。

| 记录内容 | 帮助回答的问题 |
| --- | --- |
| **关系背景** | 当前关系阶段、参与者与现实约束是什么 |
| **关键事实与未知** | 已经确认什么，哪些来自转述，什么还没核实 |
| **建议与选择** | 为什么建议这样做，你实际选了哪一步 |
| **行动与真实反馈** | 是否谈过、双方是否同意、有没有执行、结果怎样 |

进展分别记录为提议、本人选择、双方同意、实际尝试和动作完成。继续咨询时，先核对上次行动与实际变化，再决定下一步。

你可以要求查看、纠正、暂停、恢复、导出、删除某个案例，或撤销全部记忆。脚本保留每个案例最近50次更新，最多30个案例。持续咨询也可以只使用当前对话。[查看档案操作说明](references/core/memory.md)

## 安装与使用方式

### 安装完整目录

可以在 GitHub 点击 **Code → Download ZIP**，解压后将包含 `SKILL.md` 的完整目录命名为 `emotion-master`，按所用工具的 Skill 安装入口或目录规则加载。

也可以用 Git 获取。

```shell
git clone https://github.com/Surge-Dan/emotion-master-skill.git emotion-master
```

安装时保留 `references/`、`resources/`、`scripts/` 等配套目录。加载后，直接说“使用 emotion-master”并描述问题，支持 `$技能名` 的工具也可以使用上面的调用示例。

### 普通咨询

通过对话提供问题、聊天或材料即可开始。可以要求持续讨论，也可以一次性生成可保存的话术、协商草案、复盘或工作表。[查看咨询工作表](resources/consultation-workbook.md)

### 可选本地记忆

档案脚本需要 **Python 3.9+**，只依赖标准库。宿主需要具备本机文件访问和脚本执行能力，启用前按档案说明取得授权并指定仓库外的私人目录。

换设备时，可由你主动导出精简档案并在新环境导入咨询上下文。跨会话续聊取决于宿主能否实际读取已获授权的档案目录。

## 隐私、同意与求助边界

- 本地档案使用别名和最少必要摘要，默认不保存完整聊天、截图和原始文件，目录须位于 Git 仓库与 Skill 目录之外。
- 档案为**本地明文**，使用本机账户权限。设备共用、云同步或备份可能产生可访问副本，存储位置由你选择。聊天和附件的处理还取决于宿主的数据规则。
- 默认单人咨询。伴侣共同参与时，先确认参与者、共同讨论范围和记录意愿，旧的个人陈述需要相应授权才能共享。
- 对方拒绝、要求停止联系或撤回同意时，停止当前方向的推进。亲密互动以当下自愿和可撤回的同意为前提。
- 依恋、爱情语言和人格标签只在合适范围内帮助描述体验。关系判断根据具体行为、持续变化和现实条件形成。
- 出现暴力、威胁、强迫、监控或自伤线索时，优先处理当下安全与可用支持。涉及心理治疗、伤情、性健康、财产和离婚法律事项时，结合所在地寻找相应专业帮助。

具体约定见[材料与案例规则](references/core/evidence.md)、[本地档案说明](references/core/memory.md)和[安全支持分支](references/knowledge/safety-and-support.md)。

## 本地开发与验证

在仓库根目录运行。

```shell
python -X utf8 scripts/validate_knowledge.py
python -X utf8 -m unittest discover -s tests -v
```

当前验证基线包括11项档案脚本测试、5个独立合成咨询场景，以及技能格式、相对链接和来源记录检查。合成场景包含实际 PNG 和文本文件读取，发现的去留流程歧义已修正并复核。

工程测试在 Windows 与 Python 3.9.9 执行。真实用户效果、其他系统的文件锁行为，以及模糊长图、各类办公文件、音视频和跨会话召回的宿主兼容性，仍需实际验证。[查看验证范围](resources/validation.md)
