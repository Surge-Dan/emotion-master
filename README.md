# 情感大师 · Emotion Master

你的情感大师，教你暧昧追求、聊天分析与回复、长期相处、冲突修复和分手复盘，结合情绪支持、自我觉察、事实梳理及双方需求与投入分析，帮你看清关系、搞懂自己，关键时刻递上话术和行动建议，争取让你登上爱情的巅峰，别半路谈成了爱情的牛马！

## 长期关系优先，覆盖关系全周期

从一个具体问题开始，逐步了解背景，整理事实和需要，给出明确首选、依据与代价，再落到话术、协商或行动。后续根据实际反馈更新建议。默认一个人来咨询，伴侣共同参与时先确认讨论、共享与记录范围。

## 能帮你干什么

| 场景 | 给你的帮助 |
|---|---|
| 这句话怎么回 | 一条贴合你口吻的回复，以及面对不同反馈的下一步 |
| 暧昧、追求、邀约 | 看清当前互动，设计具体表达和容易回应的提议 |
| 聊天看得头大 | 确认谁在说话，拆出事实、推测与未知 |
| 只有自己在主动 | 结合发起、兑现、回应与修复，校准投入 |
| 有期待又说不出口 | 把委屈整理成能商量的具体请求 |
| 长期相处总在同类问题上吵 | 讨论金钱、孩子、工作、家务、个人空间等生活选择 |
| 分手后想重新找到自己 | 回看真实经历、支持与生活资源 |
| 想重新认识伴侣 | 用五问先预想再向本人核实，更新了解 |
| 家务、照护总要自己盯 | 把发现、规划、执行与跟进拆开，形成可协商的完整责任 |
| 金钱、父母、生育和工作安排谈不拢 | 梳理现实条件、各自底线与可行选项 |
| 信任破裂、亲密差异、要不要继续 | 核实关键事实，给首选、代价与改变建议的条件 |

## 使用

将仓库作为一个完整技能目录安装到支持 Skill 的工具中。Codex 项目安装时可放到 `.agents/skills/emotion-master/`，并保留目录中的全部引用文件。

可以直接说“使用 $emotion-master，帮我看看这段聊天，先给一句我能直接发的话，再讲讲理由”。

想全面复盘时，可以说“使用 $emotion-master，帮我梳理长期关系，先处理最影响我们的一个问题，未知信息留空”。完整学习大麦哥视频时使用原有七模块流程。

第一次默认了解关系阶段、最近发生的具体事情、这次最想解决的问题。可以提供文字、聊天截图或文件，实际可读范围取决于宿主工具。急着回消息时会先给可发送的版本。

## 可选本地档案

明确同意后可把关系别名、关键事实、建议和实际进展保存在指定的私人目录，用于下次续聊。默认不保存原始聊天和图片。支持查看、修改、暂停、恢复、导出、删除与撤销。用户可以一直使用无档案模式。

档案工具需要Python 3.9+，只依赖标准库。文件使用明文与本机账户权限，没有内置加密或双人分权存储，存放目录须在Git仓库和Skill目录之外。具体命令与授权规则见[本地档案说明](references/core/memory.md)。

## 方法来源

保留 Michael大麦哥《关于爱情，我终于想明白了几件事》整期蒸馏的六个主题与结尾五问。相关原文定位见各能力卡。

结合狗头军师项目的情绪承接、证据拆分、回复编排、口吻校准、反馈分支和投入校准方法，整理成适用于本技能的按需参考。具体版本和许可见 NOTICE.md。

原视频转写已全文通读，逐字听校及跨平台逐帧比对仍待进行。专业来源的核查范围见逐项记录。本地自动检查和合成场景评测验证工程与流程行为，真实用户效果、不同宿主的图片/文件读取能力仍需实际验证。
