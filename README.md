# 情感大师 · Emotion Master

你的情感大师，教你暧昧追求、聊天分析与回复、长期相处、冲突修复和分手复盘，结合情绪支持、自我觉察、事实梳理及双方需求与投入分析，帮你看清关系、搞懂自己，关键时刻递上话术和行动建议，争取让你登上爱情的巅峰，别半路谈成了爱情的牛马！

## 能帮你干什么

| 场景 | 给你的帮助 |
|---|---|
| 这句话怎么回 | 一条贴合你口吻的回复，以及面对不同反馈的下一步 |
| 暧昧、追求、邀约 | 看清当前互动，设计具体表达和容易回应的提议 |
| 聊天看得头大 | 确认谁在说话，拆出事实、推测与未知 |
| 只有自己在主动 | 结合发起、兑现、回应与修复，校准投入 |
| 有期待又说不出口 | 把委屈整理成能商量的具体请求 |
| 长期相处总在同类问题上吵 | 讨论金钱、孩子、工作、家务、个人空间等生活选择 |
| 分手后想重新找到自己 | 回看真实经历、支持与生活资源 |
| 想重新认识伴侣 | 用五问先预想再向本人核实，更新了解 |

## 使用

将仓库作为一个完整技能目录安装到支持 Skill 的工具中。Codex 项目安装时可放到 `.agents/skills/emotion-master/`，并保留目录中的全部引用文件。

可以直接说“使用 $emotion-master，帮我看看这段聊天，先给一句我能直接发的话，再讲讲理由”。

想全面复盘时，可以说“使用 $emotion-master，按七个模块带我梳理这段关系，未知信息先留空”。

## 方法来源

保留 Michael大麦哥《关于爱情，我终于想明白了几件事》整期蒸馏的六个主题与结尾五问。相关原文定位见各能力卡。

结合狗头军师项目的情绪承接、证据拆分、回复编排、口吻校准、反馈分支和投入校准方法，整理成适用于本技能的按需参考。具体版本和许可见 NOTICE.md。
